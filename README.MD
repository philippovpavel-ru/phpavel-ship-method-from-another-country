# Доставка из другой страны для WooCommerce

Плагин добавляет в WooCommerce настраиваемый способ доставки **«Доставка из другой страны»**: фиксированная стоимость, страна-склад, список товаров и автоматическая установка статуса заказа после оформления.

Способ доставки показывается только тогда, когда все товары в корзине входят в его список. Остальные способы доставки в это время скрываются. Плагин также не позволяет смешивать в одной корзине товары из разных складов.

## Возможности

- Кастомный способ доставки с фиксированной стоимостью.
- Настройка страны-склада с выводом страны в названии способа.
- Выбор товаров, к которым применяется способ доставки.
- Запрет смешивания товаров из разных складов в одной корзине.
- Автоматическое скрытие обычных способов доставки для «иностранных» товаров.
- Обработка ситуации, когда товар убрали из списка метода, пока он уже лежит в корзине.
- Поддержка нескольких методов доставки с разными странами и списками товаров.
- Выбор статуса заказа после оформления, включая кастомные статусы WooCommerce.
- Очистка корзины из уведомления без перехода на страницу корзины.
- Совместимость с классическим checkout и Checkout Block / Store API.
- Совместимость с HPOS (High-Performance Order Storage).

## Требования

- WordPress с поддержкой WooCommerce 8.0+.
- WooCommerce 8.0 или новее. Проверено на WooCommerce 11.2.2.
- PHP 8.3 или новее.
- Активированный WooCommerce.

## Установка

1. Скопируйте папку `phpavel-ship-method-from-another-country` в `/wp-content/plugins/`.
2. Активируйте плагин в разделе **Плагины** WordPress.
3. Перейдите в **WooCommerce → Настройки → Доставка**.
4. Выберите нужную зону доставки и нажмите **Добавить способ доставки**.
5. Выберите **«Доставка из другой страны»**.
6. Заполните настройки метода и сохраните изменения.

Для установки из архива упакуйте папку плагина в ZIP и загрузите его через **Плагины → Добавить новый → Загрузить плагин**.

## Настройка способа доставки

Настройки находятся в модальном окне экземпляра метода внутри выбранной зоны доставки.

| Поле | Назначение |
| --- | --- |
| **Название способа** | Название, которое видит покупатель при оформлении заказа. |
| **Статус налога** | Облагается ли доставка налогом. |
| **Стоимость** | Фиксированная стоимость доставки. |
| **Статус заказа после оформления** | Статус, который получит заказ с этим способом доставки. Можно оставить пустым. |
| **Страна-склад** | Страны, откуда доставляются товары. Названия стран добавляются к названию способа доставки. |
| **Товары** | Товары, к которым применяется способ доставки. Поиск работает по названию и SKU. |

Список статусов заказа формируется динамически из `wc_get_order_statuses()`, поэтому в нём присутствуют как стандартные, так и кастомные статусы, зарегистрированные через фильтр `wc_order_statuses`.

## Как работает

### Режимы корзины

| Режим | Когда возникает | Что происходит |
| --- | --- | --- |
| `empty` | Корзина пуста | Обычные способы доставки работают как обычно. |
| `plain` | В корзине только товары, которых нет ни в одном списке метода | Показываются обычные способы доставки. |
| `foreign` | Все товары корзины входят хотя бы в одну общую группу склада | Показываются только ставки методов «Доставка из другой страны». |
| `stale` | Часть товаров входит в складскую группу, а часть уже не входит ни в один список | Оформление блокируется, покупатель видит названия товаров, которые больше не доставляются выбранным способом. |
| `mixed` | Товары относятся к разным складам | Способы доставки скрываются, оформление блокируется. |

### Добавление товаров в корзину

- Если в корзине уже есть товары нашего метода, добавлять можно только товары из того же склада.
- Если в корзине есть обычные товары, нельзя добавить товар, который входит в метод.
- Если в корзине есть «иностранные» товары, нельзя добавить обычный товар.
- При нарушении правил товар не добавляется, а покупатель получает уведомление с кнопками перехода к оформлению и очистки корзины.

### Если настройки метода изменились, пока товар лежит в корзине

Если администратор убрал товар из списка метода, а покупатель уже добавил его в корзину, корзина переходит в режим `stale`:

- обычные способы доставки не показываются;
- оформление блокируется;
- в уведомлении перечисляются товары, которые больше не доставляются выбранным способом;
- покупатель может удалить эти товары или очистить корзину.

### Несколько способов доставки и складов

Можно создавать несколько методов «Доставка из другой страны» с разными странами и списками товаров.

Совместимость корзины определяется по группам товаров:

- методы с одинаковым списком товаров считаются одной группой;
- если списки пересекаются, товары можно оформить вместе только тогда, когда существует хотя бы один метод, покрывающий весь набор товаров корзины;
- товары из разных групп нельзя оформить одной доставкой.

### Несколько зон доставки

- Плагин собирает экземпляры метода из всех зон доставки, включая зону «Остальные миры».
- Стоимость, страна, название и статус заказа берутся из экземпляра той зоны, которая подошла под адрес покупателя.
- Совместимость корзины рассчитывается глобально по всем настроенным методам, независимо от текущей зоны.
- Если товар входит в метод другой зоны, но не входит ни в один метод текущей зоны, он всё равно считается «иностранным», а обычные способы доставки для него скрываются.

### Статус заказа

- Статус применяется к заказу, в котором выбран способ доставки этого плагина.
- Поддерживаются классический checkout и Checkout Block / Store API.
- Если платёжный шлюз меняет статус в том же запросе (например, BACS ставит «На удержании»), выбранный статус применяется повторно.
- Более поздние изменения статуса от платёжной системы (webhook, повторная оплата) не перезаписываются.
- Статусы `failed`, `cancelled` и `refunded` не заменяются выбранным статусом.
- При оплате уже существующего заказа через order-pay статус не навязывается.
- Если поле не заполнено или сохранённый статус больше не существует, используется стандартное поведение WooCommerce.

### Очистка корзины

Кнопка **«Очистить корзину»** в уведомлениях:

- очищает корзину через AJAX;
- перезагружает текущую страницу, не отправляя покупателя в корзину;
- без JavaScript использует запасную ссылку на страницу корзины.

## Известные ограничения

- При ручном создании заказа в админке правила корзины не применяются.
- Одинаковые списки товаров в разных зонах считаются одним складом.
- Совместимость товаров рассчитывается глобально, а не отдельно для каждой зоны.
- Фиксированная стоимость применяется к каждой посылке (пакету) WooCommerce.
- Кастомные статусы должны быть зарегистрированы стандартным способом, иначе они не появятся в настройках.
